# v0.5.0 发布核验

日期：2026-11-16。范围为本仓库的独立开源副本。

- 按源码白名单构建，未从运行实例复制数据库、邮件配置、证书、日志或部署历史。
- 虚构 Demo 从零生成，11个账号、14份周报、16个提交版本及独立的讨论、培养记录、门户和个人主页。公开演示口令仅供回环地址体验。
- 通过锁文件全新安装依赖；完整自动化测试153项通过，覆盖权限、审核、导师隔离、附件、演示库保护、脱敏扫描与ZIP打包。
- 独立临时库页面检查覆盖师生、管理员及公开页面；另验证待审核、毕业身份、非指导教师及其他学生读取附件的拒绝行为。
- 10张界面截图均来自这套新生成的Demo，已逐张查看；不含真实人员照片、联系方式或浏览器地址栏。
- README与使用手册的本地文档及图片链接已核对。
- 发布包由白名单打包器生成，包含逐文件SHA-256清单；解压后执行严格扫描，并以压缩包内容作为GitHub上传来源。

扫描器检测私有配置、数据库、密钥、常见令牌、人员路径和非示例联系方式，不把扫描通过描述为完整安全审计。截图、Logo和第三方许可另外人工查看。

实际测试输出保留在发布维护环境中，不将完整运行日志收入源码。GitHub工作流会在Node.js 24及26上重新检查，并在main分支新版本通过后创建带源码包与校验文件的Release。
