# 研栖 · LabNest v0.6.0

发布于 2026-11-16。在 v0.5.0 基础上新增中英文界面和可复制的安装任务模板。

## 本次更新

- 登录、注册、管理员、教师及学生工作台、周报、讨论、日历、课题、培养管理、门户和个人主页支持中文与英文。
- 在「外观」旁增加独立 English / 中文按钮，记住浏览器选择，保留当前页面和筛选条件。
- 用户填写的文字与表单业务值保留原文；按请求隔离语言，避免不同用户相互影响。
- 切换语言前保护尚未保存的表单修改，包含编辑器图片粘贴、格式操作和失败提交场景。
- 新增完整英文 README；两份 README 在快速体验后提供中英文安装提示词入口。
- 源码压缩包包含中英文 README、安装提示词、部署说明及虚构 Demo。

## 提供的功能

- 实验室公开门户、新闻、研究方向、成果与成员介绍。
- 管理员、教师、学生角色；注册审核、主副导师分配及指导关系范围内的数据访问。
- 周报草稿、持续修订、历史版本、图文计划、附件及困难求助分享。
- 师生动态讨论、嵌套回复、个人与团队日历、会议订阅。
- 学生档案、论文课题、毕业任务、实习与站内通知。
- 独立个人主页及 PDF、Word 简历导出。
- 六种主题色、明暗模式、跟随系统、磨砂玻璃界面和首次使用指引。

## 开源发布整理

从源码文件白名单构建，不从任何运行数据库导出。提供从零创建的虚构 Demo、独立的本机启动入口、完整中文使用手册和真实界面截图。使用通用研栖品牌，移除原运行实例的机构标识、私有路径、联系方式和部署记录，保留第三方许可证。

发布附件只含源码、锁文件、示例配置、Demo 生成资料、截图和文档；不含已生成的数据库、依赖目录、邮件配置、证书、运行日志和本机历史。首次运行 `npm ci`，随后运行 `npm run demo` 即可生成演示数据。

## 运行要求

Node.js 24+。Demo 默认地址 `http://127.0.0.1:4180/`；自己的空库默认地址 `http://127.0.0.1:4173/`。对外部署采用 HTTPS，参照部署说明。

Demo 会议和成果均为虚构示例；项目当前采用单实例 SQLite 存储，不提供分布式部署方案。
