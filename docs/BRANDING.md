# 研栖 · LabNest 标识

“研栖”用于表达科研团队共同工作、交流和成长的空间。LabNest 是项目的英文展示名；仓库地址为 `AdamRain/LabNest`。

默认标识位于 `public/lab-logo.png`，为透明背景的独立 PNG。图形以交织的弧线与一个节点表达团队协作，配色采用青绿与薄荷绿。标识由内置图像生成工具辅助生成，随本项目按 MIT 许可证提供。

该图标用于登录页、工作台、公开门户和 README。部署自己的团队网站时，可由教师在「门户内容 → 系统 Logo」上传 PNG/JPG（最大 2 MiB）替换；默认团队名、所属机构和简介也可在门户内容中维护。
